```bash

# Install dependencies
npm install

# Run dev server
npm run dev
# Visit http://localhost:3000

# Build for production (static export)
npm run build
# Output in ./out directory
```

## 🔒 How Privacy Works

```
Your Image → [Browser (WebAssembly)] → Result
                  ↑
           AI Model runs here
           No server involved
           No data leaves your device
```

All processing uses WebAssembly AI models that run entirely in your browser. Your images are never uploaded to any server.
